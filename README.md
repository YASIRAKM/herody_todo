# todo_app

A new Flutter project.
This Flutter project is a todo application using Firebase and Provider for state management. It includes the following features:

- **Authentication**: Sign in, sign up, logout, and password reset.

- **Task Management**: Add, update, list, delete, and mark tasks as done. Tasks are stored in Firebase Realtime Database and connected through API using HTTP,
    Filtering tasks according to pending , completed.

- **Responsive Design**: The app is responsive and works on all devices.

- **Provider for State Management**: The apps state is managed efficiently using provider - Authentication state and Task Management state.
